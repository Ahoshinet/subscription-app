# Subscription Manager v1.0.0

Subscription Manager v1.0.0 is the first stable release of the v1 line.
Development since v0.16.0 focused on regression coverage, type safety,
reliability, and release validation rather than adding new features.

## Stability and regression coverage

- Added regression tests for authentication, subscription lifecycle, payment
  methods, reminders, Gmail transactions, Paidy state, settings, API contracts,
  and shared utilities.
- Added automated tests and code-quality checks for every push and pull
  request.
- Hardened authentication and subscription session handling, synchronized
  settings, payment method state, Gmail responses, and Paidy errors.

## Type and input hardening

- Added runtime validation for synchronized settings and UI selection values.
- Added validation for payment and subscription icon names before rendering.
- Strengthened dashboard subscription, navigation route, tab, and settings
  types.
- Normalized UI error handling while preserving existing behavior.
- Unified the subscription status switch with the Settings switch color on
  both iOS and Android.
- Unified login and registration failures with the App's native error dialogs
  instead of shifting the authentication form with a persistent error banner.
- Kept Billing Cycle and Currency picker rows at a consistent height and
  vertically centered text in the Edit form.

## Security and release tooling

- Updated the vulnerable PostCSS transitive dependency to a patched version.
- Added automated release-tag and version verification.
- Added Android performance measurement tooling and GitHub Release publishing.
- Added enforced test-coverage thresholds.
