## 第12条（Googleアカウント連携・Gmailデータの利用）/ Article 12 (Google Account Integration and Gmail Data Usage)

本サービスは、オプションのGoogle連携機能（Gmail連携）を提供しています。本機能を利用した場合、以下のとおり取り扱います。

**【取得するデータ】**  
Gmailの読み取り権限（`gmail.readonly`）を使用し、Paidy合同会社（@paidy.com）から送信された「ご利用確定のお知らせ」メールのみを対象に、取引金額・日付・加盟店名を端末上で解析します。メール本文の生データはサーバーに送信・保存しません。

**【アクセストークンの保管】**  
Googleアクセストークンはお使いの端末のセキュアストレージにのみ保存します。運営者サーバーには送信しません。

**【サーバー保存データ】**  
解析済みのサマリー情報（合計金額・対象月・取引一覧）のみを運営者サーバーに保存します。

**【利用目的】**  
Paidyの請求金額をサブスクリプション一覧に自動表示するためにのみ使用します。第三者への提供・広告目的での利用は行いません。

**【連携解除】**  
設定画面からいつでもGoogle連携を解除できます。解除時はアクセストークンおよびサーバー上の解析データを削除します。

本機能はGoogle LLC（米国）のAPIを利用しています。Googleのプライバシーポリシーは <https://policies.google.com/privacy> をご参照ください。

---

The Service provides an optional Google integration feature (Gmail integration). When this feature is used, the following applies:

**[Data Accessed]**  
Using Gmail read-only permission (`gmail.readonly`), the Service accesses only emails from Paidy Co., Ltd. (@paidy.com) with the subject "ご利用確定のお知らせ" (transaction confirmation), and parses transaction amounts, dates, and merchant names on-device. Raw email content is never transmitted to or stored on the Operator's servers.

**[Access Token Storage]**  
The Google access token is stored only in the device's secure storage (SecureStore). It is never sent to the Operator's servers.

**[Server-Side Data]**  
Only the parsed summary (total amount, billing month, transaction list) is stored on the Operator's servers.

**[Purpose of Use]**  
This data is used solely to automatically display Paidy billing amounts in the subscription list. It is never shared with third parties or used for advertising.

**[Revoking Access]**  
You can disconnect Google integration at any time from the Settings screen. Upon disconnection, the access token and all parsed data on the server will be deleted.

This feature uses the API provided by Google LLC (USA). For Google's Privacy Policy, please visit <https://policies.google.com/privacy>
